# Quazilang vs Rust -O0 та інші мови — 20 бенчмарків

20 тестів рядками, компілятори стовпцями. Виміряно Rust 1.99.1 (`-C opt-level=0`), інші значення перенесені без змін із попереднього набору.

## Методика

- Rust: `rustc 1.99.1 -C opt-level=0 -C debuginfo=0 -C overflow-checks=off -C target-feature=+crt-static -C panic=abort -Awarnings`. `--sysroot` і повний шлях до rustc локальні для середовища. **Rust без LLVM-оптимізацій `-O1/-O2/-O3`**. `overflow-checks=off` прибирає перевірки арифметичного переповнення для кращої семантичної відповідності C, а не піднімає рівень оптимізації.
- Rust зібрано в **статичний PIE ELF**. Розмір після `strip --strip-all`. Інші дані після попереднього `strip --strip-unneeded`. Технічно це різні режими strip; обидва видаляють символи налагодження, але абсолютна порівнянність залежить від формату ELF.
- Час компіляції: один повний запуск компілятора на кожен тест. Rust включає запуск rustc і лінкування; без інкрементального кешу. Інші вимірювання не повторювалися.
- Час виконання: медіана **5 окремих запусків кожного тесту**, включно із запуском процесу. Rust виконаний 5 разів та звірений з результатами решти 17 варіантів.
- GCC/Clang C/C++/Fortran: `-O0`, Zig: `Debug`, Swift: `-Onone`; інші налаштування з попереднього набору збережені. Rust -O0 **не є release**.
- Java `.class` і Kotlin `.jar` не включають повний JVM runtime. Бінарники Swift у попередньому наборі динамічні. Розмір скриптів та Quazi JIT не зіставний з розміром нативних виконуваних файлів, тому виключено з третьої таблиці.
- Величини нижче — результати тестового контейнера, не рейтинг мов у цілому. Особливо малі значення (близько 1–3 мс) чутливі до накладних витрат запуску та шуму системи.
